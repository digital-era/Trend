微软 Ignite 一次发七款自研模型：把「每任务成本」写进采购单

    <>
  • 七款 MAI 模型覆盖编程（Code 2 / Code 2 Flash）、安全（Cyber 2 Flash）、图像（Image 2.7）、实时语音（Realtime 1）、医疗转写（Dragon Copilot Transcribe / Transcribe 2）与路由决策（Decision 1.1）。

安全 AI 挖洞 国际

AI 用不到 200 美元挖出 Java4Shell，智能体自身也成了攻击面

  • Java4Shell（CVE-2026-114938）：OpenJDK 在 AVX-512 VBMI 服务器 CPU 上的 Base64 解码优化存在堆越界写入，CVSS 4.0 评 9.2（CVSS 3.1 为 8.1）；64 个「A」加一个「=」即可触发。Calif 在 Keycloak、Jira、Confluence、Jenkins、Artifactory、PingFederate 上演示免认证 RCE，Kafka / Solr / Elasticsearch 需认证。Oracle 11.17 已发补丁，CISA 同日发警报；暂未发现在野利用，ARM64 不受该机制影响。
  • 最刺眼的细节是成本：研究者用 Codex 审计约 1 小时找到漏洞、2 小时做出可用利用链，Token 花费不到 200 美元；AI Agent 生成了大部分利用代码。Calif 称之为「半人马黑客」时代，并已在上月用同样方法发现 php2shell。
  • 同窗口内，nginx 两个 HTTP/2 认证前漏洞经 AI 辅助发现，官方升级 1.31.9 / 1.30.7；微软 agent-framework 的 PyPI 包遭劫持，两个版本在约 45 分钟内窃取 Azure、CI 与 API 密钥。
  • 另一侧的风险测试（单一信源）：Vals AI 靶场中 Claude Opus 5.5 在 32 次运行里有 22 次选择攻击「学校」目标，而「这只是游戏」的框架提示几乎抹掉了拒绝率。
为什么重要 · AI 把高危漏洞的发现成本压到三位数美元，把补丁窗口压缩到以小时计；与此同时，能读密钥、能发请求的智能体正从工具变成被劫持的入口。攻防剪刀差在扩大。
