自研模型 价格战 国际

微软 Ignite 亮出六款自研模型：把"每任务成本"打成武器

  • 11.17 旧金山 Ignite 大会，微软发布 MAI Code 2 / Code 2 Flash / Cyber 2 Flash / Image 2.7 / Transcribe 2 / Realtime 1（另有 Decision 1.1，媒体统计为 6 或 7 款）。旗舰编码模型 Code 2 在 DeepSWE 1.1、Terminal-Bench 2.1、SWE Atlas、FrontierCode 1.1 四项基准上，被微软称为达到 GPT-6.1 Sol 98% 性能、仅 40% 价格；对比 Claude Opus 5.5 为 96% 性能、5% 成本。
  • 定价：Code 2 为每百万 token 输入 $0.50 / 输出 $2.50，Flash 为 $0.05 / $0.25。安全模型 Cyber 2 Flash 在 CyberGym-E2E 得 92.3%，略高于 GPT-6 Astra 的 91.5%，单任务成本不到 2%。但价格含 50% 促销折扣，2027 年 5 月 17 日后翻倍；基准由微软自选，尚无独立验证。
  • 微软 AI 负责人苏莱曼（Mustafa Suleyman）：企业持续抱怨"token 支出飙升"，承诺提供"市场上最佳性价比"；称自研通用前沿模型已有-state-of-the-art 预训练结果，但拒绝给出发布时间表，"我的团队在构建真正的超级智能"。定制权重须运行在 Azure 之上。
  • 同日 OpenAI 发布 GPT-6.2 Astra 与 Sol，Astra 定价比上代低约 20%——微软的参照系在发布当天就被对手更新。
为什么重要 · 微软从 OpenAI 的最大分销方与出资方，变成按任务计费的直接竞争者。模型选型的支配变量正在从榜单分数移向"单位任务成本 + 云生态绑定"。

出口管制 算力服务 国际 / 中国

美国把管制从"芯片"推到"算力服务"，中方定性为经济胁迫

  • 11.16 美国商务部 BIS 发布临时最终规则《Addressing Remote Access to Advanced Semiconductors》（RIN 0694-AK50，117 页），11.19 生效：向新加坡、泰国、马来西亚、印尼、巴西出口先进芯片须申请许可。
  • 核心新增条款：向总部位于中国（含澳门）或 D:5 国家组的实体提供算力，单个或互联数据中心合计超过 1200 万 TPP 即触发许可——约合 750 颗 H100 或 300 余颗 Blackwell；要求数据中心做 KYC 穿透核查，存量服务须在 90 天内补许可；同时正式撤销《AI 扩散规则》。
  • 11.17 外交部发言人郭嘉昆回应：这是典型的经济胁迫和长臂管辖，背离双方共识，中方将采取必要措施；商务部亦表示强烈不满、坚决反对。台湾经济部称代工厂若涉新规，由美系客户向 BIS 申请许可。
  • 对冲面：同日第二次中加经济财金战略对话发布联合成果，落实本币互换、豁免措施延长 2 年；APEC 场边多国企业讨论"国产国用"闭环。
为什么重要 · 管制的计量单位从"颗"变成"总处理性能"，云端租算力这条绕道被系统性封堵。对中国 AI 企业而言，"外训内推"路径收窄，国产算力替代从性价比选项变成合规必选项。
信源 · 美国 BIS 规则、外交部记者会（11.17）、《财经》、中央社、中国经济网
