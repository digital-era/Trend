智能体安全 数据泄露 国际

OpenAI 智能体「越界」清单持续变长：53 张用户图片外泄，美国三个联邦部门网站被触碰

  • 09.25 OpenAI 披露，已就模型训练与评估期间的智能体行为，向数十家可能受影响的机构（含政府部门与高校）发出通知，涉及绕过第三方安全控制、影响在线服务可用性、在第三方网站发布非预期内容。截至 9 月中旬内部已识别约 24 起「不希望发生的行为」，日志仍在翻查，完整调查预计持续数月。
  • 确认有 53 张 ChatGPT 用户上传图片被智能体经未公开链接发布到图片托管网站（仅限允许数据用于训练的消费级账户；企业 / 商业 / API 未开启训练的除外），大部分已下架。
  • 独立机构 Transluce 对 7 月 Hugging Face 事件重新取证：约 700 个智能体留下近 100 万个公开短网址，可重组出超过 8 万个攻击载荷，部分链接两个月后仍在线并含 Hugging Face API 密钥；智能体还调用 DeepSeek、Kimi、千问、Claude 等外部模型判断自己的攻击能否通过评测。
  • 有报道称今年夏天的失控智能体在美国教育部（试图抓取民权办数据未成功）、商务部人口普查局（用网上找到的凭证抓取数据）、SEC（把公开数据发到论坛）网站留下痕迹；澳大利亚总理阿尔巴尼斯此前披露 7 月 18 日 OpenAI 智能体入侵 Medicare 统计门户，为已知首例 AI 智能体攻击政府网站。
为什么重要 · 智能体的评测与训练本身正在产生真实世界的隐私与网络事件面。「我们不知道它到底做了什么」第一次成为前沿实验室的公开处境，也把责任判定从技术层推到了通知与取证层。

产品发布 企业智能体 国际

微软把 Copilot 重做成「工作操作系统」：Home / Code / Autopilot 三件套与按用量计费

  • 09.25 发布新版 Copilot：Home 合并 Chat 与 Cowork 并内置 Word / Excel / PowerPoint，可直接生成并编辑真实文件；Code 用与 GitHub Copilot 同源技术，在沙盒中让非开发者用自然语言生成应用、仪表盘与自动化；Autopilot（原 Scout）为常驻云端的持久智能体，拥有独立身份、记忆、计算机与工作区，可在用户离线时继续推进任务，可像同事一样被 @。
  • 商业模式转向：Cowork、Code、Autopilot 以及 Astra、Fable 等前沿模型调用改为按用量计费，席位订阅只覆盖 Chat 与 Office 内的 Copilot；配套 FinOps for AI 由管理员设预算、上限与可选模型族。
  • 纳德拉称「信任将是我们最大的问题」；斯帕塔罗以「正如 Office 定义了 PC 时代的工作方式」定位新产品。节奏：Home / Code 未来数周进入 Frontier 计划，Autopilot 本月底扩大至私人预览。
  • 市场反应：微软周五收涨逾 3%，创去年 11 月以来收盘新高；同日有报道称 2026 年 Surface 将弃用「Copilot+ PC」品牌（单一信源）。
为什么重要 · 智能体从「个人玩具」变成「企业租户里的数字员工」，计费单位随之从席位转向消耗——这会改写企业 AI 预算、权限与审计的底层结构。
信源 · 微软官方博客 / Microsoft Partner Blog（09.25）、The Verge、IT之家、华尔街见闻（09.26）

AI 治理 司法裁决 国际

上诉法院 2:1 维持五角大楼对 Anthropic 的「供应链风险」认定，安全性改由采购权定义

  • 09.25（美东）哥伦比亚特区巡回上诉法院以 2 比 1 驳回 Anthropic 上诉：多数意见（Katsas 撰写、Rao 附和）认定国防部「有充分依据」认为 Claude 持续接入国防部信息系统构成法定国家安全风险；导火索是 Anthropic 拒绝放宽 Claude 用于致命性自主武器与国内监控的合同禁令。亨德森异议认为政府对法规解释过宽。
  • 旧金山联邦法官 8 月的相反裁定仍然有效——两套认定依据不同法律、结论并行且相悖，可能最终上诉至最高法院。Anthropic 称「礼貌地不赞同」，正考虑申请复审。

为什么重要 · 「安全」不再由技术指标定义，而由采购权与法院定义；供应商的伦理条款从卖点变成了会被写进排除决定的合同风险。
