  • 11.20，腾讯混元宣布 Hy4 正式开源，权重同步上线 GitHub、Hugging Face、ModelScope、GitCode；随 Hy3 preview、Hy3、Hy4 preview、Hy4 flash 一并开放，混元 LLM 系列至此全量开源。Hy4 为 MoE 架构，语言主干 770B 总参 / 每 token 激活 49B / 100 万 token 上下文，同批开放指令版、FP8 量化版与预训练 base，并附 System Card：训练数据仅纳入 PoC 生成、漏洞修复等防守性网络安全内容，剔除攻击性数据。

模型安全 知识产权 国际 / 中国

思维链成为护城河：OpenAI 将推理提取成功率从 54% 压到 0.2%，并点名中国实验室

  • 11.20，OpenAI 发布《Combatting adversarial distillation》：在聚合 6 个攻击模型的内部自适应黑盒评测中，从历史请求提取受保护推理的成功率由 GPT-6 Astra（原防护）的 54.0% 降至 GPT-6.2 Astra（新防护）的 0.2%；从当前请求提取由 22.9% 降至 0.9%。数字为厂商自测，未经外部复现。
  • 机制三层：推理与产生它的会话历史绑定（改写旧消息即丢弃后续推理）、旧模型家族被禁止读取新推理、输入/输出及工具调用分类器；网络层面按账号网络执法，每周处置数千至数万账号，部分改进回补至 GPT-6 Astra。
  • 内部对照实验显示：用完整推理轨迹训练的学生模型，在网络安全基准上普遍优于仅用推理摘要训练的学生——OpenAI 因此把防蒸馏定义为安全议题而非纯商业议题。Anthropic 的同类实验为 SWE-bench Verified 80.4%（完整轨迹）对 71.8%（摘要）。
  • 政策化：OpenAI 重申 2 月已就 DeepSeek 相关活动向国会简报，并沿用 9 月将某次提取活动「核心集群」归因于与月之暗面相关个人的说法（未独立证实，未见 Moonshot 回应）；明确支持 Chip Security Act、AI OVERWATCH Act 与 MATCH Act。
为什么重要 · 模型护城河正从「权重不开放」延伸到「推理过程不可迁移」。竞争战场移到 API 语义层，也把中美模型之争推向立法与制裁工具。
