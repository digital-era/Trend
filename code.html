用「人话」讲透 RSI · KDJ · MACD

不看公式推导，不讲玄学。用一个比喻 + 一个场景，让你彻底明白这三个指标到底在"看"什么。

🌡️ RSI = 体温计 🎢 KDJ = 弹簧秤 🚗 MACD = 油门表
指标一 · RSI 相对强弱指标

🌡️ 市场的体温计

Relative Strength Index ｜ 一句话：最近 N 天里，多头和空头谁打得猛？

💡 本质比喻：把市场当成一个发烧的病人。RSI 就是体温计——
• 体温 ≥ 70℃（RSI>70）：烧得厉害（涨太猛），该物理降温了 → 超买
• 体温 ≤ 30℃（RSI<30）：失温了（跌太狠），该进被窝了 → 超卖
• 体温只是"度数"：它不告诉你病人什么时候退烧，只告诉你现在烧到几度！

📐 根原理：一场"拔河比赛"的力量测量

过去 N 天（常用 14 天），把每一天分成两派：

💪 涨的那几天

收盘价比前一天高 → 涨幅加总，得到「平均上涨力量」

📉 跌的那几天

收盘价比前一天低 → 跌幅加总，得到「平均下跌力量」

RSI = 100 × 涨的力量 ÷ (涨的力量 + 跌的力量)

所以 RSI 天生就被摁在 0 ~ 100 之间：

• 如果 14 天全在涨 → 分母全是涨 → RSI = 100（烧到极限）
• 如果 14 天全在跌 → 涨的力量 = 0 → RSI = 0（冰冻极限）
• 多空势均力敌 → RSI = 50（不烧不冷，正常体温）

🎯 用途与实战读法

RSI 数值市场状态经典做法
70 ~ 100🔴 超买（涨过头，情绪亢奋）警惕回调，不追高
50 附近⚪ 多空平衡（方向不明）观望或看更大周期
0 ~ 30🟢 超卖（跌过头，恐慌抛售）关注反弹机会
背离（价新高，RSI不新高）⚠️ 体力透支最强的预警信号
⚠️ 大坑提醒：体温计在单边行情里会"失灵"——强趋势中 RSI 可以在 80 以上"高烧"好几个月不退。 就像运动员体温偏高不是病，是状态好。别一看到 70 就做空！
指标二 · KDJ 随机指标

🎢 装了弹簧的价格秤

Stochastic Oscillator ｜ 一句话：现在的价格，站在最近一段行情的哪个位置？

💡 本质比喻：想象一个电梯井，井壁就是最近 9 天的最高价（天花板）和最低价（地板）：
• 价格贴着天花板（KDJ≈100）→ 已经被顶到极限，往上没空间了
• 价格贴着地板（KDJ≈0）→ 被压到极限，往下没空间了
• 而 J 值就是那根被压扁/拉长的弹簧——它可以被压到 0 以下、拉到 100 以上（超调），但弹簧迟早要弹回来！

📐 根原理：三兄弟是这样诞生的

RSV = 100 × (今收盘 − 9日最低) ÷ (9日最高 − 9日最低) K = RSV 的平滑（老司机，反应慢一点） D = K 的平滑 （更老的司机，反应更慢） J = 3K − 2D （K和D的"夸张版"，弹簧最灵敏也最疯）

这就是为什么 J 值可以超过 100 或低于 0：它不是被限制在区间里的，它是 K 和 D 拉开差距时的"夸张放大器"。

🟡 金叉（K 上穿 D）

灵敏的年轻人（K）从下往上穿过迟钝的老人（D）→ 短期动能转强，偏多信号

🟣 死叉（K 下穿 D）

年轻人率先掉头向下，跌破老人 → 短期动能转弱，偏空信号

🎯 用途与实战读法

信号含义用法
K、D < 20 后金叉低位弹簧压到底再弹开抄反弹的经典信号
K、D > 80 后死叉高位弹簧拉到顶再松手逃顶的经典信号
J > 100 或 J < 0弹簧被过度拉伸/压缩短线极值，随时回弹
低位/高位背离价新低但 KDJ 不新低反转预警
⚠️ 大坑提醒：KDJ 太灵敏，就像弹簧一碰就晃。在震荡市里它是神，在单边趋势里它是坑—— 强势上涨中它会天天"超买死叉"骗你下车。周期越短，假信号越多。
指标三 · MACD 指数平滑异同均线

🚗 市场的油门与刹车表

Moving Average Convergence Divergence ｜ 一句话：涨跌的"速度"在加快还是减慢？

💡 本质比喻：价格是车，均线是司机的平均驾驶习惯：
• 快线（EMA12）= 年轻司机，脚踩油门反应快
• 慢线（EMA26）= 老司机，开得稳、变道慢
• DIF（快线 − 慢线）= 两车距离 → 油门踩多深
• DEA（DIF 的平滑）= DIF 的"平均速度"
• 红绿柱（DIF − DEA）= 加速度！ 柱子在变长 = 越踩越深；柱子缩短 = 开始松油门

🔑 最关键的直觉：价格创新高，但柱子在缩短 = 车还在往前开，但已经开始松油门了——这就是顶背离！

📐 根原理：速度 = 位移的差分

DIF = EMA(12) − EMA(26) ← 快慢两车拉开了多远 DEA = DIF 的 9日平滑 ← 这个"距离"的平均水平 柱子 = 2 × (DIF − DEA) ← 距离还在不在扩大（加速度）

均线跟得上涨价，DIF 就在 0 轴上方（多头油门区）；均线跌下来，DIF 落到 0 轴下方（空头刹车区）。 所以 0 轴就是多空油门的分界线。

🎯 用途与实战读法

信号人话翻译含义
DIF 上穿 DEA（金叉）油门踩下，速度超过均值做多信号
DIF 下穿 DEA（死叉）刹车踩下做空/离场信号
0 轴上方金叉本来就在快车道又踩油门强势，信号更可靠
顶背离（价新高，柱缩短）车还在前进但已松油门最强的见顶预警
底背离（价新低，柱缩短）车还在后退但已松刹车最强的见底预警
⚠️ 大坑提醒：MACD 是"滞后指标"——它像老司机的反应，总是慢半拍。 震荡市里会反复金叉死叉来回打脸。它的强项是看趋势和动能衰竭（背离），不是精确抄底逃顶。

🧠 终极心法：KDJ 告诉你"现在贵不贵"，RSI 告诉你"情绪疯没疯"，MACD 告诉你"趋势还在不在"。
没有圣杯，只有互相验证——三个都指向同一方向时，才敢重仓下注。
🛡️ 最后一句大实话：所有指标都是由过去的价格算出来的，它们不预测未来，只是把已经发生的事 换一种更容易读懂的方式呈现。工具没有错，错的是把工具当预言家。
