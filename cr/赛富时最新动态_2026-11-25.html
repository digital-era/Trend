行业 TOP 12026-11-04AI智能体需求加速验证

企业软件竞争从Copilot辅助转向Agent执行，实际工作流使用成为新的竞争指标

Salesforce于11月4日公布Agentforce Coworker使用量三个月增长21倍，显示市场关注点正在由生成式AI问答转向能够调用企业数据、完成多步骤任务的智能体。该案例属于厂商自身产品披露，不等于整个行业的统一增长率，但对企业级Agent落地具有直接示范意义。

对Salesforce横向映射

Salesforce拥有CRM业务上下文、客户权限和工作流入口，具备把Agent嵌入业务流程的天然优势；但Microsoft Copilot、ServiceNow及其他垂直Agent厂商同样争夺企业工作流入口。最终竞争指标应是付费渗透率、任务成功率、客户续约及单位调用毛利，而不是单一使用量。

信源：Salesforce News，2026-11-04，官方产品公告。

行业 TOP 22026-10-28平台化竞争加剧

Slack开放Code API，企业协作入口进一步向智能体和开发工作流开放

Salesforce于2026-10-28发布Slack Code API，强化智能体、团队协作与代码工作流之间的连接。该动作反映企业软件的竞争边界从单一应用功能向跨应用编排和协作接口延伸。

对Salesforce横向映射

Slack与Salesforce CRM、Agentforce及数据平台结合，有望增加平台内交互频次并降低工作流流失；但Microsoft Teams、GitHub、Atlassian等生态掌握大量开发者和协作入口，API开放也会提高互操作竞争与安全治理要求。

信源：Salesforce News，2026-10-28，Introducing the Slack Code API。

行业 TOP 32026-10-27利好平台治理能力，成本仍待验证

Agent Fabric增强智能体失效与成本控制能力，企业级Agent治理成为产品竞争点

Salesforce于2026-10-27宣布扩展Agent Fabric，强调自动识别并停止失控成本及智能体故障，避免影响客户业务。随着Agent从试点走向生产，调用成本、权限、安全、审计和故障恢复逐渐成为企业采购的必要条件。

对Salesforce横向映射

若治理工具降低企业部署风险，可加快Agentforce从试点到生产的转化，并形成平台差异化；反之，若客户发现Agent运维复杂或总体拥有成本过高，采购预算可能流向更轻量的模型/API和专业Agent平台。

信源：Salesforce News，2026-10-27，Salesforce Expands Agent Fabric。
